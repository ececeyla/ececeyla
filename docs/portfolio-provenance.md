# Notes on the engineering portfolio

## Formula Racing

The [Devrim 26 sensor PCB repository](https://github.com/ececeyla/metu_formula) contains the seven-sheet EasyEDA schematic in a **private** repository, with collaborator annotations retained. The profile diagram summarizes the electrical blocks and is not a photographic or routed-board representation. Fabrication, bench-testing, vehicle integration, and technical-rule compliance are contributor-reported milestones.

## KIT and UPC

The KIT and UPC repositories separate imported historical evidence from reconstructed tools and synthetic test data, and document work that has not been independently verified on hardware during this GitHub import.

## Publication

The original Formula schematic, company/institution research materials, or team-provided code should be released publicly only with appropriate permission. The profile README intentionally contains higher-level project descriptions rather than raw restricted research material.

A GitHub profile README only appears on the public GitHub profile if the special `ececeyla/ececeyla` repository is **Public**.
